hud.ttf is Roboto Mono Regular (Copyright 2015 The Roboto Mono Project Authors),
licensed under the SIL Open Font License 1.1 — see OFL-RobotoMono.txt.

The filename is role-based: the app loads "fonts/hud.ttf" for the HUD text and the
ofxGui panels, so the bundled font can be swapped without touching code. Roboto Mono
is monospace, chosen so the live telemetry readouts keep fixed-width digit alignment.
